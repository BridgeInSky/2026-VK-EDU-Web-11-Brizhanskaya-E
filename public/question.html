Как правильно использовать Bootstrap в Django проекте?

Подскажите, пожалуйста, как правильно интегрировать Bootstrap в Django проект. Нужно ли копировать файлы в статику или лучше использовать CDN? Какие есть плюсы и минусы у каждого подхода?

Теги: django bootstrap python
Алексей | 2 часа назад

Ответы (3)

8

Я рекомендую использовать локальную копию Bootstrap. Это дает несколько преимуществ:
1. Работа без интернета
2. Контроль над версиями
3. Быстрая загрузка после первого раза
4. Возможность кастомизации

CDN проще для начала, но для production лучше использовать локальные файлы. Можно также использовать django-bootstrap5 библиотеку.
