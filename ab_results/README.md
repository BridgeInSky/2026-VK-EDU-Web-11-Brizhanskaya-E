# Результаты нагрузочного тестирования (ДЗ7)

## Конфигурация тестирования
- Утилита: Apache Benchmark (ab)
- Количество запросов: -n 1000
- Одновременных соединений: -c 10
- Тестовый WSGI сервер: простой обработчик (без Django)

## Результаты

| № | Тип запроса | RPS | Относительная скорость |
|---|-------------|-----|----------------------|
| 1 | Статика (nginx) | 460.39 | 1x (базовый) |
| 2 | Статика (gunicorn) | 126.79 | 0.27x (в 3.6 раза медленнее) |
| 3 | Динамика (gunicorn) | 23.19 | 0.05x |
| 4 | Динамика (nginx proxy) | 3153.34 | 6.85x |
| 5 | Динамика (nginx + cache) | 3206.43 | 6.96x |

## Выводы

1. **Статика через nginx в 3.6 раза быстрее**, чем через gunicorn, потому что nginx использует sendfile для передачи файлов.

2. **Proxy_cache даёт небольшое ускорение (1.7%)** для динамических запросов, так как:
   - Тестовый WSGI сервер генерирует ответ очень быстро
   - Нет тяжёлых вычислений или запросов к БД

3. **Рекомендации:**
   - Статику всегда отдавать через nginx
   - Для динамики использовать проксирование с кэшем
   - При реальном проекте с БД и сложной логикой эффект от proxy_cache будет больше
